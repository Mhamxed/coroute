# Coroute

Frontend: created with react.js
Backend: created with JAVA spring boot
Database: Microsoft SQL server



## 1. Contexte et Objectif

Le projet **CoRoute** est une application web de covoiturage inspirée de BlaBlaCar, permettant de mettre en relation des conducteurs et des passagers pour des trajets interurbains.

### Objectif principal (prototype)

Créer une plateforme simple permettant :
- aux conducteurs de proposer des trajets
- aux passagers de rechercher et réserver une place

---

## 2. Périmètre du prototype

Le MVP doit inclure uniquement les fonctionnalités essentielles pour valider le concept.

### Gestion des utilisateurs

- Inscription / Connexion
- Profil utilisateur (nom, email, téléphone)
- Rôle implicite : conducteur ou passager

---

### Gestion des trajets

- Création d'un trajet :
  - Ville de départ
  - Ville d'arrivée
  - Date et heure
  - Nombre de places
  - Prix par place

- Consultation des trajets disponibles

---

###  Recherche

- Recherche par :
  - Ville de départ
  - Ville d'arrivée
  - Date

---

###  Réservation

- Réserver une place sur un trajet
- Gestion du nombre de places restantes
- Confirmation de réservation

---

###  Tableau de bord utilisateur

- Voir :
  - ses trajets publiés
  - ses réservations
